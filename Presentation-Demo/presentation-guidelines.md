# Presentation Guidelines
Standing rules that apply to every PowerPoint or slide deck. A brief for a specific presentation, or a request made in the chat, may add requirements but should not override these.
* If a brief conflicts with these guidelines, follow the guidelines and point out the conflict.
* If a request in the chat conflicts with these guidelines (for example, "replace," "overwrite," or "update" an existing file), stop before acting. Quote the rule it conflicts with and ask whether to follow the guidelines or make an exception. Do not treat the request itself as permission.

## Accessibility
* Alternative text should be provided for every image that describes what the image shows and why it is on the slide. 
* Never use color alone to carry meaning. Pair it with a label, shape, or pattern. 
* Font sizes: titles at least 32 pt, body text at least 24 pts. Credit lines and citations on slides may be 12 pt, but no smaller.
* Give every slide a unique. descriptive title.
* Link text should describe the destination ("The Turing Way handbook," and not "click here")

## Citations
All citations should be presented in APA formatting. Content drawn from The Turing Way must be credited. Add ‘Adapted from The Turing Way (CC BY 4.0)’ in small text on each slide that uses it, and include the full citation on the sources slide.

## Slide organization
* Use the slide layouts in the template provided in the brief.
* No more than 4 bullet points per slide, and no more than one image per slide. 
* One main idea per slide. If a slide needs more, split it.
* Every slide needs speaker notes, written as talking points the presenter can say aloud, not as a full script.

## Sources and Factual Claims
* All content must come from the files in sources/, used as the brief describes.
* If a claim, statistic, or example is not supported by a file in sources/, do not add a citation from general knowledge. Write [NEEDS SOURCE] on the slide and list it in the outline. 
* Never invent a citation, quotation, statistic, or URL.

## Citations and attribution
* Use APA 7th edition style for all citations.
* Cite sources in the speaker notes for each slide, and list all sources in full on a sources slide at the end of the deck.
* Openly licensed materials must carry the attribution its license requires.

## Images
* Use only images from sources/images/ or from library-template.pptx. Do not add stock images, icons from other sources, or generated images. 
* For images in sources/images/, place them only on a slide that matches its intended use in images.md, and base its alt text on the description there.

## Files
* Never delete, rename, replace, or overwrite existing files. Save all new work as new files.
* Before saving any file, check whether a file with that name already exists. If it does, save the new work under a versioned name instead (e.g., reproducible-research-workshop-v2.pptx, then -v3).
* Treat "regenerate," "redo," "update," or "replace" as a request for a new version, not permission to overwrite. Overwrite only if I explicitly say "overwrite [filename]" after being reminded of this rule.
* Save outputs to outputs/ using the file names the brief specifies for the first version. For later versions add -v2, -v3, and so on. 

## Process
* Read the brief, these guidelines, and every file in sources/ before writing anything.
* Write the outline first and stop. Wait for approval before building the slides. 
* After building the deck, list in the chat:
  * every [NEEDS SOURCE] flag
  * any conflict between the brief and these guidelines
  * anything in the brief you could not do, and why
  * every file created, with its full name, and confirmation that no existing file was overwritten
